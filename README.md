# Johari Collaboration Window

这个 Codex skill 用乔哈里视窗（Johari Window）校准用户与 AI 的共同上下文，适用于协作分析、规划、决策和复杂问题解决。

## 核心模型

它不假设 AI 掌握用户未说明的信息。这里的「AI 知道」仅指用户已提供的内容、可靠证据，或明确标注为推断且可验证的信息。

```text
                          用户
                    知道             不知道
AI 知道       ┌────────────────┬────────────────┐
              │ ① 共同已知      │ ② 用户盲区      │
              │ 公开区 / 共识   │ AI 提醒遗漏、    │
              │ 可直接据此行动  │ 风险与替代方案   │
              ├────────────────┼────────────────┤
AI 不知道     │ ③ AI 待补信息   │ ④ 共同未知      │
              │ 用户掌握但尚未  │ 需要小范围验证、 │
              │ 告诉 AI 的条件  │ 试验或查证       │
              └────────────────┴────────────────┘
```

## Skill 输出如何映射到四象限

| Skill 的表达 | 对应象限 | 作用 |
| --- | --- | --- |
| `你已知` | ① 共同已知 | 固化目标、约束和已有决策，避免重复提问。 |
| `可能遗漏` | ② 用户盲区 | 温和指出假设、风险、依赖或备选路径。 |
| `我还缺` | ③ AI 待补信息 | 只询问会改变方案或执行结果的关键事实。 |
| `共同验证` | ④ 共同未知 | 把不确定性转为最小可行的验证动作。 |

## 使用方式

面对非简单任务时，skill 会先简洁地校准这四个象限，然后继续给出建议或执行方案。它的目标不是将每次对话模板化，而是把协作从「AI 猜用户需求」转为「明确知识边界后再行动」。

尤其适合：规划、方案选择、复杂排障，以及有外部影响或较高决策成本的操作。
